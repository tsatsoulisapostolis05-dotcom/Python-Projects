# Python Calculator

A simple command-line calculator created while learning Python.

## Features

- Addition, subtraction, multiplication, and division
- Accepts whole numbers and decimal numbers
- Handles invalid number input
- Prevents division by zero
- Rejects unsupported operators

## Run it

1. Download `calculator.py`.
2. Open it in Visual Studio Code.
3. Run the file with Python.
4. Enter two numbers and choose `+`, `-`, `*`, or `/`.
