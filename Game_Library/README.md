# Python Game Library

A simple command-line game library created while learning Python.

## Features

- Add games with a title, genre, platform, and rating
- View all the games in your library
- Rating must be a number between 0 and 10
- Gives a recommendation message based on the rating
- Handles invalid number input
- Rejects invalid menu choices

## Run it

1. Download `game_library.py`.
2. Open it in Visual Studio Code.
3. Run the file with Python.
4. Choose `1` to add a game, `2` to view all games, or `3` to exit.

## Rating guide

| Rating | Message |
| ------ | ------- |
| 0 - 4 | This game is not recommended. |
| 4.1 - 7 | This game is recommended. |
| 7.1 - 10 | This game is highly recommended. |
